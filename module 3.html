Document Structure

Learn how <html>, <head>, and <body> form the skeleton of every webpage.

Headings & Text

Use <h1>–<h6> for headings and <p> for paragraphs to structure content.

Links & Images

The <a> tag creates hyperlinks and <img> embeds visuals into your page.

Every HTML file starts with a doctype declaration and wraps content in <html>, <head>, and <body> tags.

html 
<!-- Basic skeleton -->
<!DOCTYPE html>
<html>
  <head>
    <title>Page Title</title>
  </head>
  <body>
    <!-- content here -->
  </body>
</html>

Use <h1>–<h6> for headings (h1 = largest) and <p> for body text.

html
<h1>Main Heading</h1>
<h2>Sub Heading</h2>
<p>A paragraph of text.</p>

The <a> tag creates hyperlinks using the href attribute. The <img> tag embeds images with src and alt.

html 
<a href="https://example.com">
  Visit Example
</a>
<img src="photo.jpg"
     alt="Description">
